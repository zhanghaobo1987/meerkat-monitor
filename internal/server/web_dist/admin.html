主题管理

支持 Komari 主题格式（komari-theme.json + dist/），如 LuminaPlus、Emerald、Glass 等

如何获取主题？

从 GitHub 下载主题 Release 的 ZIP 包（如 Komari-Theme-LuminaPlus）， 点击右上角「上传主题」即可安装。主题包内需包含 komari-theme.json 清单与 dist/ 构建产物。 激活后前台页面将切换为主题渲染，数据通过 Komari 兼容 API（/api/nodes 等）提供。
